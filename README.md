# e-plantShopping

A plant e-commerce web application built with React and Redux.

## About

e-plantShopping is a shopping cart application where customers can browse and purchase plants. It features a fully functional cart system with Redux state management for handling product additions, removals, and quantity updates.

## Features

- Browse plants by category
- Add/remove items from cart
- Adjust item quantities
- Real-time cart total and item count
